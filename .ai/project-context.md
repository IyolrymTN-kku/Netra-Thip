# Netra-Thip Project Context

## Overview
Netra-Thip is an Enterprise ASOC and Vulnerability Management Platform. It aggregates, executes, and normalizes various cybersecurity tools into a single unified Dashboard with AI-driven reporting.

## Tech Stack
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS v4
- Prisma (PostgreSQL) & MongoDB
- NextAuth (Session-based authentication)
- n8n automation workflow
- Kali Linux scanner host

## Core Tools Integration
- **CLI Tools:** AutoPentestX, Guardian-cli, VULS
- **REST API Services:** Metlo, Sirius Scan
- **File Ingestion:** Caido, SILENTCHAIN AI
