# AI Agent Prompt Library

This library stores standard responses and prompts for the AI agent in the Netra-Thip project.

- **Start of Task:** Restate understanding with Goal, Affected files, Security-sensitive concerns, and Proposed approach.
- **CORS Proxy Task:** Focus on server-side Next.js route, input validation, and secure upstream handling. Do not expose secrets.
- **PDF Export Task:** Ensure user is authenticated, validate scan ownership, and prevent path traversal.
- **PR Review Task:** Check for blocking issues, security risks (auth bypass, RBAC mistakes, leaked secrets), test gaps, and maintainability.
